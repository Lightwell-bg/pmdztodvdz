# Быстрый старт

Только шаги. Подробности: [README_RU.md](../README_RU.md). Файл `.env` не нужен: у плагина нет ключей.

1. Соберите установочный ZIP (на своём компьютере, из корня проекта):

   ```bash
   php bin/build-zip.php
   ```

   Путь к архиву и новая версия печатаются в конце: `dist/_<N>bginfo-pmzh-dvzh.zip`. Только посмотреть список файлов: `php bin/build-zip.php --dry-run`.

2. Установите плагин: в админке **Плагины → Добавить новый → Загрузить плагин**, выберите ZIP, **Установить**, **Активировать**. Easy Digital Downloads 3.2+ должен быть активен.

3. Создайте товар в EDD: **Загрузки → Добавить**. Название, цена (и обычная цена, если используете), без файлов. Сохраните как черновик или опубликуйте скрытым.

4. Откройте **ПМЖ → ДВЖ → Настройки**: выберите товар (и вариант цены, если он есть), страницу с анкетой, укажите адрес политики конфиденциальности, нажмите **Сохранить**. В блоке «Готовность продажи» должно быть «Всё готово».
   Укажите также ориентир дохода (сумма, валюта, дата проверки): без него результат «Основные условия предварительно подтверждаются» невозможен, средства всегда «нужна проверка».

5. Разместите шорткод на странице под существующим заголовком `h2` с `id="anketa-dvzh"`, перед разделом «Законы, официальная процедура и формы»:

   ```text
   [bginfo_pmzh_dvzh_questionnaire]
   ```

6. Проверьте на **staging** (не на боевом сайте): в EDD включите тестовый режим и тестовые ключи Stripe, пройдите анкету → «Перейти к оплате» → тестовая карта `4242 4242 4242 4242` → инструкция и «Скачать PDF». Полный список проверок: раздел «Проверка оплаты и PDF на staging» в [README_RU.md](../README_RU.md).

7. Убедитесь, что CDN и кэш не кэшируют REST плагина:

   ```bash
   curl -sI https://ВАШ-САЙТ/wp-json/bgdvzh/v1/state
   ```

   В ответе должно быть `Cache-Control: no-store, private`.

8. Запустите тесты (локально, из корня проекта):

   ```bash
   php .tools/phpunit.phar -c phpunit.xml.dist
   ```

   Ожидается `OK`.
